АСТРО-МАСТЕРСКАЯ

Сайт работает по адресу https://lera-astro.github.io (организация lera-astro, репозиторий lera-astro.github.io).
Обновление: загрузить изменённые файлы в этот репозиторий, через 1–2 минуты сайт обновится.

Ниже инструкция, как выложить сайт заново на другой хостинг, если понадобится.

Сайт состоит из обычных файлов, сервер не нужен. Подойдёт любой бесплатный хостинг статических сайтов.

ВАРИАНТ 1. GitHub Pages (аккаунт WeLove13)
1. Распакуйте архив на компьютере.
2. На github.com нажмите «+» → New repository. Имя, например, astro. Тип Public (бесплатные Pages работают с публичными репозиториями). Create repository.
3. В новом репозитории: «uploading an existing file» (или Add file → Upload files). Перетащите в окно ВСЁ содержимое распакованной папки: index.html, manifest.json, иконки, папки css, fonts, js. Commit changes.
4. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
5. Через 1–2 минуты сайт будет по адресу https://welove13.github.io/astro/ (адрес покажет та же страница Settings → Pages).
Обновление: загрузить изменённые файлы тем же способом поверх старых.

ВАРИАНТ 2. Netlify (если GitHub неудобен)
1. Зарегистрируйтесь на app.netlify.com (бесплатно).
2. Откройте app.netlify.com/drop и перетащите распакованную папку целиком.
3. Netlify даст адрес вида https://имя.netlify.app. В настройках сайта имя можно поменять.

ВАЖНО
- Сайт нужно открывать по адресу https://..., а не двойным щелчком по файлу: иначе расчёты не запустятся.
- Ключи ИИ на сайте не хранятся: каждый пользователь вводит свои ключи в «Ещё», они живут только в его браузере.
- Любой, кто знает адрес, может открыть сайт, но без своих ключей ИИ у него ничего не напишется. Тексты правил (промпты) лежат в папке js и видны тем, кто откроет код страницы.
- Для Леры: открыть адрес в Safari → «Поделиться» → «На экран Домой». Дальше всё по вкладке «Ещё» → «Как пользоваться».
